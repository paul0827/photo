# 日誌照片選擇

GitHub Pages 網址：https://paul0827.github.io/photo/

將 index.html 與 .nojekyll 放在 main 分支根目錄。Settings → Pages → Deploy from a branch → main → /(root) → Save。

訪客可以瀏覽照片與勾選，自動儲存至現有後端。管理員入口連到受保護的原網站，使用既有管理員 ChatGPT 帳號登入後匯出全部 Excel。

此儲存庫只放前端，照片與選擇保存在後端。後端需維持上線。不同瀏覽器各自保留選擇；原网站和 GitHub Pages 的瀏覽器草稿獨立，但匯出會包含兩邊提交的結果。
